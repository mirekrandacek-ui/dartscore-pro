How to play and score darts with DartScore Pro

DartScore Pro provides the scoreboard and turn tracking; the players still decide the targets and throw the darts. Before starting, choose the game mode, add the players, configure the match rules and press Start.

X01: 101, 301, 501 and longer games

In X01 every player begins with the selected starting score. The value of each valid throw is subtracted from the remaining total. The aim is to reach exactly zero before the other player or team.

A single scores the number shown on the board, a double scores twice that number and a triple scores three times the number. The outer bull scores 25 and the inner bull scores 50.

Finishing rules

With an unrestricted finish, a player can reach zero with any valid final dart. When Double Out is selected, the final dart must finish the leg on a double or the inner bull. When Triple Out is selected, the final dart must satisfy the selected triple finishing condition. DartScore Pro uses the match settings selected before the game when it validates the finish.

Busts

If a visit would take the score below zero, or would otherwise make a finish invalid under the selected finishing rule, the visit is treated according to X01 bust rules and the player's score is not allowed to continue into an impossible state.

Legs and sets

A leg is one complete race from the starting score to zero. A match can be configured to require multiple legs and, when sets are used, multiple sets. DartScore Pro keeps the current leg and set state together with the active player.

Cricket

Cricket focuses on 15, 16, 17, 18, 19, 20 and Bull. A single counts as one mark, a double as two marks and a triple as three marks. A number is closed after three marks.

Once you have closed a number, additional hits can score points while an opponent still has that number open. Bull follows the same mark idea: the outer bull counts as one mark and the inner bull as two. A player normally needs to close all required targets and satisfy the points condition to win.

Around the Clock

Around the Clock is a target-progression game. Players work through the board in numerical order and finish with Bull. Instead of reducing a starting score, the important information is the next target each player needs to hit. DartScore Pro keeps that target visible and advances it after a valid hit.

Roulette modes

Roulette modes add a changing target to the session. The app draws or presents the required target and tracks whether the current player hits or misses it. This creates a practice format in which players cannot simply repeat the same preferred segment.

Entering scores

For classic X01, DartScore Pro supports score entry by individual darts and a round-total method. Individual-dart entry is useful when you want the app to know each hit. Round-total entry is faster when a player already knows the total value of the three-dart visit.

Tip: Check the active player before confirming a visit. The app deliberately keeps turn order visible so a score is not accidentally entered for the wrong person.

Playing against the robot

When practising alone, choose one of the available robot difficulty levels. The computer opponent provides an automated score progression so a single player can practise match rhythm rather than only throwing isolated groups of darts.

Team play

In supported X01 games, players can be assigned to teams. Team play is useful for doubles-style home matches because the scoreboard can keep the player sequence and team result together instead of requiring a separate paper calculation.

Saving and continuing

DartScore Pro stores relevant game state locally on the device. If a match is interrupted, an unfinished game can be continued when that saved state is available. Local match records are also used for statistics and recent-performance views.

Before the first throw

  1. Select the game mode.
  2. Choose the starting score or mode-specific settings.
  3. Set legs, sets and finishing rules where applicable.
  4. Add players or teams and choose their order.
  5. Choose a robot difficulty if you are practising alone.
  6. Press Start and enter each visit as the game progresses.
